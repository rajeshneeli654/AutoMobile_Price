# Automobile Price Analysis

## 📌 Project Overview
This project analyzes automobile market data to identify key factors that influence car prices in the US market.

## 🎯 Objective
- Identify significant variables affecting car prices
- Understand relationships between engine specifications and price
- Provide business insights for pricing strategy

## 🛠 Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## 🔍 Key Analysis Performed
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Correlation analysis
- Data visualization

## 📊 Key Insights
- Engine size and curb weight strongly impact price
- Mileage shows a negative correlation with price
- High-performance cars tend to be priced higher

## 📁 Project Structure
- Notebook: `automobile_price_analysis.ipynb`
- Dataset: `data/`
- Visuals: `visuals/`
